## Универсальная система

- pipeline.py: очистка приватной сцены; геометрия; материалы; нормализация размеров; нижний центральный pivot; bake трансформаций; нормали; manifold, ненулевая площадь, триангуляция и бюджеты; BLEND; FBX только meshes; чистый импорт FBX и сравнение геометрии/материалов; manifest и SHA256.
- build_assets.py: три оригинальных builder-рецепта и запуск с обязательной новой папкой --out.
- roblox_prepare.luau: общие prepare/validate, сопоставление частей по именам, восстановление масштаба/расположения/цветов, Anchored, коллизии, pivot и атрибуты происхождения.
- validate_stage03.luau: готовая проверка трёх экземпляров; исполнялась через MCP в Edit, Play и сохранённой копии.
- preview_assets.py: превью в отдельном процессе; камеры и свет не записываются в исходные BLEND.
- README.md: правила расширения системы и повторного запуска.

Единицы: 1 stud = 0.28 m; Blender Z-up → Roblox Y-up. Для проверенной пары FBX exporter/importer требуется разворот горизонтальных осей меша на 180° вокруг Y. Это зафиксировано в общей подготовке и проверено визуально; произвольные сторонние FBX этим тестом не покрыты.

## Предупреждения, ошибки и исправления

1. Steam обновил установленный Blender до 5.3.0, hash 02f0899d78e3. Проверки на 5.2.3 не заявляются.
2. Blender сообщает WinError 5 при записи кэша extensions вне проекта; экспорт и рендер завершились с Exit 0.
3. В первой сборке исправлен неактуальный matrix_world: добавлен view_layer.update() до bake. Создана новая сборка 002, старая не перезаписана.
4. Первая попытка превью не имела World; создание World исправило ошибку. preview_retry.log: Exit 0.
5. Первая загрузка Roblox отклонена из-за неразрешённой папки. После разрешения пользователя загрузка успешна; перемещения файлов ради обхода не было.
6. Импортированные экземпляры потребовали настройки масштаба, ориентации и цветов по manifest. Общая prepare-функция выполнила её; последующая validate подтвердила результат.
7. Studio предупредила, что локальное изменение package отключает автоматическое обновление до публикации/revert. Исправленный экземпляр сохранён в RBXL; исходный облачный package не обновлялся. Для повторной вставки нужно снова применять prepare.
8. Диалог Download a Copy не принимал управление: «failed to activate captured window». Повторное получение окна не помогло. Пользователь сохранил копию; после закрытия диалога GUI снова работал, открытие/закрытие/повторное открытие агент выполнил сам.
9. В Output три сообщения для rbxassetid://203785492: Asset type does not match requested type. Этот ID не принадлежит новым моделям; существующие объекты для исправления не изменялись. Утверждение «в Output нет ошибок» не делается.
10. Измерение топологии непосредственно облачного Roblox Mesh и полностью автономное сохранение через GUI пока не доказаны. Проверки геометрии FBX, экземпляров, Play и локальной сохранности выполнены.
