# Stage 0.9 — PARTIAL

26.11.2026. Это промежуточная работа, не готовая к использованию для данных игроков. Исходный Stage 0.8 не менялся. Локальная копия place и резервная копия сохранены рядом с этим отчётом; обе пока побайтово соответствуют Stage 0.8 и не содержат новой системы.

Аудит: ResourceService и MerchantService используют один SessionInventory; EconomyCore выполняет продажу без yield. ResourceService сейчас создаёт пустую сессию и удаляет её при выходе, поэтому подменять её сохранением без изменения жизненного цикла небезопасно. Названия девяти ресурсов профиля совпадают с ResourceCatalog. Исходники Stage 0.8 скопированы в `src`, отдельный backup place — `STAGE_08_BACKUP.rbxl`.

Сделаны изолированные прототипы `prototype/ProfileCore.luau` и `prototype/PlayerDataService.luau`, mock и тесты. Они не подключены к Rojo mapping, игровым сервисам, Roblox Studio или облаку. 46 проверок прототипа прошли в Luau CLI, 22 теста экономики Stage 0.8 также прошли на оригинальных модулях. Статический анализ новых файлов завершился с кодом 0 для основных тестов и модулей. Результаты — в соответствующих `.log`.

Незавершено: безопасная интеграция с инвентарём, отказ операций после истечения lease, обработка записи при закрытии, бюджет и autosave, BindToClose, регрессия интегрированной игры, Studio и все реальные DataStore-проверки. Прототип использует изменяемую таблицу профиля и сам не защищает её от внешней записи: до интеграции требуется единый контролируемый API мутаций и блокировка действий в состояниях loading/closing/blocked. Прототип не реализует миграцию или управление бюджетом, реальную уникальность owner и обработку всех последствий потери lease. Реальный повторный вход, multiplayer и восстановление после краша не проверены. Отдельная закрытая Experience пользователем разрешена, но не создана; API доступа для основной игры не включался.
